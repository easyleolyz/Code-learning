6)解释打印二进制的函数
从我们自然而然的思考使用短除法得到每一位的数字
从高位到低位或者进行，拼起来这些字符串
int,long都有对应的固定的位数，我们只需要得到对应的位的数字

```java
    public class Main {

    public static void printBinary(int num){
        int cnt = 0;
        for(int i = 31;i>=0;i--){
            int j = 1<<i;
            System.out.println(num&j);
            cnt++;
        }
        System.out.println("-------");
        System.out.println(cnt);
    }
    public static void main(String[] args) {
        int a = 78;
        System.out.println(a);//打印出来是给人看的，已经转成了十进制的形式
        printBinary(a);//我们自己定义的函数，打印出来是二进制的形式
        System.out.println("====a====");//

    }
}

'''
    1. 我们的思路分解为1..2..4..8..16..32..64..
    输出结果为
    78  0 0 0 0......64 0 0 8 4 2 0 已经成功分解了但是我们要打印数字
    2. 怎么得到对应的数字呢,
    System.out.println(num&j);--->System.out.println((num&j)==0 ? 0:1);
    3. 为什么不是对称式呢,System.out.println((num&j)==1 ? 1:0);
    因为不对称,我们分解的数位分为两类 0 或者是 2的(0,1,2,...)次方,
    2的(0,1,2,...)次方--->显现在对应数位上为1即可
    所以(num&j)==1不是这类情况,应该为(num&j)==pow(2,i) ? 1:0
    4. 如果我们试着运行看看
    System.out.println((num&j)==1 ? 1:0);的结果全为0
    (num&j)==pow(2,i)结果正确,但是规范的来讲pow(2,i)是double类型的,我们需要做个类型转换。
    5. 如果不用pow,完成对应的代码应该是怎样的


'''
