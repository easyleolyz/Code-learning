补充一个问题,以下代码是否正确
```java
import static java.lang.Math.pow;
public class Main {

    public static void printBinary(int num) {
        for (int i = 31; i >= 0; i--) {
            System.out.print((num&(1<<i))==pow(2,i) ? "1":"0");
        }
        System.out.println();
    }
    public static void main(String[] args){
        int i = 0b0011010;
        printBinary(i);

    }
}
```
问题 A：pow(2, i) 是 double，比较时会发生数值提升
pow(2, i)算出为double类型
== 比较时，Java 会把左边的 int 提升为 double 再比较
这本身就不符合“位运算”的习惯写法，性能也更差（每一位都调用一次pow）
问题 B：第 31 位（符号位）会直接错
当 i = 31 时：

(1 << 31) 在 int 中是 0x80000000，这是一个 负数

(num & (1<<31)) 的结果要么是 0，要么是 0x80000000（仍然是负数）

但：pow(2, 31) 是 2147483648.0（正的 double）

所以即使 num 的符号位是 1，左边会是 -2147483648，永远不可能等于右边的 +2147483648.0，导致最高位判断必错。

结论：只要涉及 bit31，这个比较逻辑就不成立。

int i = Integer.MIN_VALUE;
得到错误答案:00000000000000000000000000000000

只要 num 是 负数（即 bit31 = 1），你这套“与 pow(2,i) 比较”的逻辑就会把最高位必然打印成 0。
