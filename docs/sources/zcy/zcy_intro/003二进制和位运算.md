分位两种形式---
---1.给一个十进制的负数例如-6，请你写出对应的二进制
方法--->写出其相反数6的二进制数--->先减1--->再按位取反
-6--->6--->0110--->0101--->1010
---2.给一个二进制的负数例如1010，请你写出对应的十进制是多少
方法--->先按位取反--->再加1--->将二进制转化为十进制
1010--->0101--->0110--->6--->-6

4)打印二进制；直接定义二进制，十六进制的变量
在java中我们直接打印对应的二进制数的字符串
```java
    public static void main(String[] args){
        int a = 78;
        SystemOut.println(a);//打印出来是给人看的，已经转成了十进制的形式
        PrintBinary(a);//我们自己定义的函数，打印出来是二进制的形式
        SystemOut.println("====a====")//分割线

        int b = -6;
        SystemOut.println(b);//打印出来是给人看的，已经转成了十进制的形式
        PrintBinary(b);//我们自己定义的函数，打印出来是二进制的形式
        SystemOut.println("====b====")//分割线

        //以上为输出的表现，以下我们关心如何通过输入二（或者n）进制的形式直接定义一个数
        int c = 0b1001110;
        //0b(1001110),0b表示二进制形式,
        System.out.println(c);
		printBinary(c);
		System.out.println("===c===");

        //使用十六进制定义
        int d = 0x4e;
        //0x(4e),0x表示十六进制
        SystemOut.println(d);
        printBinary(d);
        SystemOut.println("===d===")


    }

```

5)常见的位运算(1,&,^,~,<<,>>,>>>)
按位取反运算" ~ "
```java
    public static void main(String[] args){
        int a = 78;
        SystemOut.println(a);
        printBinary(a);
        printBinary(~a);
        int e = ~a + 1;
        SystemOut.println(e);
        printBinary(e);
        SystemOut.println("===e===")
        //那么相反数之间形式如何转换呢？
        /***
        之前已经有了,
        非负数--->减1--->按位取反
        负数--->按位取反--->加1
        0000--->1111--->0000
        1000--->0111--->1000//最小的负数相反数和绝对值都是自身
        ***/
        int f = Integer.MIN_VALUE;
        SystemOut.println(f);
        printBinary(f);
        System.out.println(-f);
		printBinary(-f);
		System.out.println(~f + 1);
		printBinary(~f + 1);
		System.out.println("===f===");
    }

```
